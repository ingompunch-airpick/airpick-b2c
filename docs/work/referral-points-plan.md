# Plan: 제휴 링크·친구 초대·포인트 v2 (단계별)

> 대표 방향 확정 2026-11-23. 금액·기간은 `appConfig` 값으로 두고 코드에 박지 않는다.  
> **각 단계는 승인 후에만 구현한다.** 0단계만 지금 진행, 1~3단계는 토스 결제 연동과 함께.

## 목표

1. **링크·코드로 온** 신규 손님은 어떤 링크·코드든 **첫 예약 5,000원 할인** (금액 동일). 광고·검색으로 그냥 온 손님은 할인 없음.
2. 데려온 사람에게 **성공했을 때만** 보상: 개인 회원 = 포인트, 회사 제휴 = 계약 페이백.
3. 재방문 손님은 할인 대신 **포인트**로 챙긴다. "처음엔 할인, 다음부터는 포인트."

## 정책 (대표 확정)

### 포인트 v2
| 항목 | 값 | appConfig 키 |
|------|----|--------------|
| 출고 완료 적립 | **실제 결제금액**(포인트·할인 제외)의 3% | `points.completeRate = 0.03` |
| 후기 적립 | **업체별 첫 후기** 2,000원 / 사진 3,000원, 같은 업체 재후기 500원 (별점 무관) | `points.reviewWon`, `points.photoReviewWon`, `points.repeatReviewWon = 500` |
| 사용 가능 시점 | 적립 즉시, 대기 없음 (결제 오픈일부터 온라인 결제에서 바로 차감) | — |
| 사용 단위 | 1,000원 | `points.spendStep = 1000` |
| 1건 최대 사용 | **한도 없음** (결제금액까지, 대표 결정 11-23) | `points.spendMaxPerBooking = null` |
| 소멸 | 마지막 예약 후 2년간 예약 없으면 전액 | `points.inactiveExpiryDays = 730` |
- 변경일 이후 예약부터 적용. 기존 예약은 5% 유지.

### 링크·코드 (제휴 + 친구 초대 공통 구조 `?ref=`)
| 항목 | 값 | appConfig 키 |
|------|----|--------------|
| 손님 할인 | 첫 예약 5,000원 (모든 코드 동일) | `referral.friendDiscountWon = 5000` |
| 인정 기간 | 클릭 후 30일, 마지막 클릭 우선 | `referral.attributionDays = 30` |
| 개인 추천인 첫 보상 | 친구 첫 예약 출고 완료 시 5,000P ("너도 5천, 나도 5천", 시즌 차등 없음. 올릴 땐 이벤트로만) | `referral.firstRewardWon = 5000` |
| 개인 추천인 재예약 보상 | 친구 첫 예약 후 1년 안의 재예약마다 2,000P | `referral.repeatRewardWon = 2000`, `referral.repeatWindowDays = 365` |
| 개인 추천인 한도 | 1년 20명 (넘으면 정식 제휴 제안) | `referral.yearlyCap = 20` |
| 회사 제휴 | 손님 할인 동일 5,000원 + 계약 페이백(`referrerCreditWon`) | 기존 `affiliates/{code}` |

### 조건 (악용 방지)
- 할인·보상은 **처음 예약하는 전화번호**만 (정규화한 번호로 과거 예약 조회, 서버에서 판단).
- 본인 추천 불가: 추천인과 전화번호·차량번호·카카오 uid 중 하나라도 같으면 할인·보상 없음.
- 보상은 **출고 완료 후**. 취소·노쇼 = 없음.
- 예약 1건에 코드 1개. 다른 할인과 중복 불가.
- 포인트는 현금 전환 불가.
- 약관: 브랜드 키워드 검색광고·쿠폰 사이트 게시 금지, 위반 시 적립 취소.

### 표시·법
- 공유 문구에 대가 사실 포함(추천보증 지침): 「이 링크로 예약하면 5,000원 할인되고, 이용하면 나도 적립금을 받아요.」
- 후기 화면에 「후기 작성 시 2,000원(사진 3,000원) 적립」 표시.
- 추천인에게는 친구 이름·번호를 보여주지 않는다. 인원수·포인트만.
- 포인트 소멸 30일 전 안내는 광고 수신 동의자에게만.
- 이용약관에 포인트·추천 프로그램 조항 추가.

## 데이터 (B2B rules·Functions 소관, 이 레포는 읽기·표시만)

- `affiliates/{code}` (기존): `type: 'partner' | 'member'`, `ownerUid`(member), `rewardType: 'payback' | 'points'` 추가. 개인 코드는 `f_` + 6자 무작위.
- `members/{uid}.referralCode` : 회원 개인 코드 (B2B Callable `getMyReferralCode`가 한 번 만들고 재사용).
- `reservations` (기존 `affiliateCode`, `affiliateCustomerDiscountWon`, `affiliateReferrerCreditWon`) + 서버가 채우는 `referralEligible: boolean`, `referralRewardStatus: 'pending' | 'granted' | 'void'`.
- `referrals/{phoneHash}` : 친구 1명 = 문서 1개. `referrerUid`, `code`, `firstReservationId`, `firstCompletedAt`, `repeatUntil`(= first + 365일), `repeatCount`.
- `pointAccounts/{uid}` (기존 `balance`) + `lastBookingAt` + 하위 `ledger/{id}`: `type`(complete | review | photo_review | referral_first | referral_repeat | spend | expire), `amount`, `reservationId`, `at`.
- `appConfig/points`, `appConfig/referral` : 위 표의 값.

## 단계

### 0단계 — 지금 (로밍도깨비 제휴, B2C만)
1. `src/utils/affiliateSession.ts`: 코드 저장을 sessionStorage → **localStorage `{ code, at }` 30일**. URL `?ref=`가 오면 덮어쓰기(마지막 클릭 우선). 30일 지나면 무시. 예전 sessionStorage 값은 한 번 읽어 옮긴다.
2. `src/context/AffiliateContext.tsx`: `applyCode(raw)` 추가 — 정규화 → `fetchAffiliateOffer` → active면 저장·적용하고 `'ok'`, 아니면 `'invalid'`.
3. `src/components/BookingModal.tsx`: 예약 금액 아래(입점 업체일 때만)
   - 코드 미적용: 작은 글씨 버튼 「할인 코드가 있나요?」 → 누르면 입력칸 + 「적용」.
   - 적용됨: 「{제휴명} 할인 {금액}원 적용」 한 줄. 입력칸 숨김.
   - 실패: 「확인할 수 없는 코드예요」.
4. 예약 접수 성공 후 저장된 코드 삭제(같은 브라우저 재사용 방지).
5. 운영(대표): B2B 관리자에서 `dokkaebi` 등록(할인 5,000원, 페이백 계약값). 업체들에 "제휴 할인분은 에어픽 수수료에서 보전" 공지. 결제 오픈 전까지 정산 때 제휴 코드 예약의 전화번호 중복을 눈으로 확인.

### 1단계 — 토스 결제 오픈과 함께 (B2B + B2C)
- 결제 금액을 서버에서 계산·검증: 할인 자격(처음 번호·본인 추천·코드 상태) 판단 → 예약에 `referralEligible` 기록.
- 포인트 v2: 적립·사용 규칙 교체(3%, 후기 적립, 1,000원 단위, 한도 없음), `lastBookingAt`·2년 소멸, ledger.
- 포인트로 결제금액 대부분(또는 전액)을 낼 때도 업체 몫은 그대로 지급: 지급대행 잔액이 모자라면 에어픽이 지급대행 가상계좌에 입금해 채운다. 0원 결제(PG 없이 접수) 경로 처리.
- 매달 미사용 포인트 총액(앞으로 나갈 비용) 확인.
- 사이트 문구 일괄 변경(「출고 완료 후 이용 금액의 5%」 등), 후기 화면 적립 안내, 약관 개정.

### 2단계 — 결제 오픈 2~4주 뒤 (B2B + B2C)
- 마이페이지 「친구 초대」 카드: 내 링크, 카카오톡 보내기·링크 복사(대가 표시 문구 포함), 초대 현황(인원·받은 포인트).
- 출고 완료 트리거: 첫 예약 보상(성수기/비수기), `referrals/{phoneHash}` 생성, 1년 안 재예약 2,000P, 연 20명 한도.
- 랜딩: 개인 링크로 오면 「친구가 보낸 5,000원 할인」 배너(추천인 이름은 성만, 예: 김○○).

### 3단계 — 측정
- 코드별 클릭 → 예약 → 출고 완료 → 건당 실제 비용(할인 + 지급 포인트 + 페이백) 표. 광고비(성수기 1만·비수기 2만)와 비교.
- 3개월 뒤 재예약률·포인트 사용으로 비율 재조정.
