# Plan: 홈 업체 카드 — PC 2열 · 이동/키/대면시간/전기차 줄

> research 생략(작은 범위). 근거: `src/utils/parkingProducts.ts`(B2C 파서·`parkingProductFacts` 이미 있음),
> B2B `ParkingProductsEditor.tsx`(키·전기차·영업시간·이동 안내 입력 칸 이미 있음).  
> **승인 전 코드 금지.**

## 목표

PC에서 업체 카드가 2개씩 보이고, 카드마다 Parkos처럼 **이동 방식 · 키 · 대면 가능 시간 · 전기차 충전**이
아이콘 줄로 보인다. 업체가 입력하지 않은 항목은 줄 자체를 안 그린다.

## 하지 않음

- 값 지어내기 (입력 없으면 줄 없음. 「무료 셔틀」「연중무휴」 같은 기본값 없음)
- 상세 시트 개편 (카드만)
- 대면 가능 시간과 예약 시간 검증 연동 (대면 시간 밖 입고 막기) — 별도
- 사설주차장 상품 노출 (입점 전)

## 화면·계정 범위

- [x] 비로그인 · 카카오 로그인 동일 (홈 목록 카드)

## 데이터

- [x] Firestore 읽기만 (B2C) — `companies.parkingProducts[]`
- [ ] **신규 필드 `meetHours`** (상품별 대면 가능 시간) → **B2B 편집기에 입력 칸 추가 필요**
  - B2B 레포 수정이라 이 plan에서는 B2C 표시만 구현. B2B는 승인 시 별도로 진행
  - 형식: `meetHours: { allDay: true } | { open: 'HH:MM', close: 'HH:MM' }` (`hours`와 같은 모양)

## 변경 체크리스트

1. **PC 2열** — `HomePage.tsx`
   - 업체 목록 섹션 폭 `max-w-lg` → PC(`md`)에서 넓힘, `PriceList`를 `md:grid md:grid-cols-2`
   - 폰은 지금처럼 1열
2. **카드가 상품을 씀** — `findParkingProduct(company, search)`로 상품을 찾아 `parkingProductFacts` 사용
3. **이동 줄 아이콘 분리** (lucide)
   | 경우 | 아이콘 | 제목 |
   |------|--------|------|
   | 주차대행 · 대면 | `PlaneTakeoff` | 출국장에서 인계 |
   | 주차대행 · 비대면 | `SquareParking` | 단기주차장에서 인계 |
   | 셔틀 | `BusFront` | 셔틀로 이동 |
   | 도보 | `Footprints` | 터미널까지 도보 |
   - 부제: 업체 입력 `transferNote` · `약 N분` (있을 때만). 없으면 지금처럼 픽업 핀 안내
4. **키 줄**
   - 맡김: **손바닥 위 키** 아이콘 (lucide에 없음 → 작은 인라인 SVG 컴포넌트 1개) · 「키를 맡깁니다」
   - 보관: `KeyRound` · 「키를 직접 보관합니다」
   - 상품에 값 없으면: 주차대행은 지금 문구 유지(키를 맡기는 서비스라 사실), 그 외는 줄 없음
5. **대면 가능 시간 줄** — `Clock`
   | 상품 | `meetHours` | 문구 |
   |------|-------------|------|
   | 대면+비대면 | 24시간 | 24시간 대면 |
   | 대면+비대면 | 09:00–22:00 | 09:00–22:00 대면 · 그 외 비대면 |
   | 대면만 | 09:00–22:00 | 09:00–22:00 대면 |
   | 대면만 | 24시간 | 24시간 대면 |
   | 비대면만 | — | 모두 비대면 |
   | 대면 있음 | 없음 | 줄 없음 |
6. **전기차 줄** — `EvCharger` · 「전기차 충전 가능」 / 「전기차 충전 불가」 · 값 없으면 줄 없음
7. 영업시간(`hours`)은 이번 카드에 넣지 않음 — 대면 시간 줄과 헷갈림. 상세에서 다룰 때 별도
8. `tsc --noEmit`
