## 변경 체크리스트 (`src/pages/MyPage.tsx`만, 필요하면 작은 컴포넌트 1개 추가)

1. 상태 묶음 함수 `reservationBucket(status)` → `'active' | 'done' | 'cancelled'`
2. **다가오는 예약 카드** (회원, 진행 중 예약이 있을 때만, 프로필 줄 바로 아래)
   - 대상: 진행 중 예약 중 `departureDate`(같으면 `departureTime`)가 가장 이른 1건
   - 표시: 상태 라벨(`getStatusLabel`), 업체명, D-day 배지, 출국 `MM.DD (요일) HH:mm · 터미널`, 귀국 `MM.DD`
   - D-day: 오늘(`todaySeoulYmd`) 기준. 출국 전 → `출국 D-n` / 출국 당일 → `오늘 출국` / 출국 후 → `귀국 D-n`, 귀국 당일 → `오늘 귀국`
   - 버튼 `예약 상세 보기` → 진행 중 탭 선택 + 해당 `ReservationCard`로 스크롤
3. **요약 타일** 「예약 N건」 → 「진행 중 N건」 (진행 중 묶음 수)
4. **내 예약 탭** (회원만): `진행 중 N` / `완료 N` / `취소 N`
   - 기본 탭: 진행 중이 1건 이상이면 진행 중, 아니면 완료, 둘 다 0이면 진행 중
   - 탭 안 정렬: 진행 중은 `departureDate` 오름차순, 완료는 `arrivalDate` 내림차순(최근 것 먼저), 취소는 그대로
   - 섹션 머리 오른쪽 건수는 지금 탭 건수
   - 후기 딥링크(`autoOpenReviewId`)가 있으면 그 예약이 속한 탭을 먼저 연다
   - 빈 탭 문구는 카피 표
5. 「설정」 섹션 제목 → 「도움말」. 안의 링크는 그대로
