# Research: 네오파킹 대비 B2C (절약·가격·안심)

> 다음: `docs/work/neoparking-compete-plan.md`  
> 입력: 네오파킹 vs 에어픽 비교 메모 + 최우선 3 (절약액 · 가격 투명성 · 안심보장)

## 1. 손님 한 명의 경로

- 시작: 홈에서 터미널·실내/야외·날짜 → 업체 카드(총액 위주).
- 중간: 상세·예약 모달에서 `PriceBreakdownCard`(기본·초과·심야 등)는 **예약 단계에서야** 자세히 보임. 카드 단계에 일당·현장 추가 정책이 약함.
- 끝: 현장 결제 · 입고 후 MY에서 사진·위치·보험. 「안심」기능은 있으나 **비교 화면에 한 블록으로 안 묶임**.
- 이탈·헷갈림: 네오는 「반값·실내·직접주차 + 절약액」이 첫 화면에 선명. 에어픽은 **총액만** 보이면 발렛 불안·현장비 공포를 못 막음.

## 3. 이미 있는 규칙 (코드·합의)

- 표시 금액 = 일정 기준 **예상·참고가**, 현장 정책·옵션에 따라 달라질 수 있음 (`complianceCopy`).
- 결제 = **현장 결제** (온라인 결제·예약금은 별도 plan).
- 후기·보험 한도·절약액 **숫자 창작 금지**. 공항 대비 절약은 **출처 있는 요금표** 필요.
- 사설주차장(직접주차) = **준비 중** — 「빨리 오픈」을 손님 카피에 단정하지 않음.
- 중개자: 사고 처리·보험은 입점 업체 중심. 「에어픽이 보장·중재」문구는 약관과 충돌 없게.
- 입고 사진·위치·보험 확인 = 인증 업체 예약 후 MY에 이미 있음.

## 4. 건드리면 안 되는 것

- [ ] Functions / rules 배포는 B2B만
- [ ] 후기·보험·절약·공항 요금 숫자 지어내기
- [ ] 발렛 비하로 자사 상품 깎기 («발렛 대신 직접주차» 톤 모방)
- [ ] 가짜 후기·별점
- [ ] 커밋·배포는 요청 시만
- 기타: 이번 기획에 **온라인 결제·사설 오픈·영문 도메인** 구현 넣지 않음 (후속)

## 5. 모르는 것 / 확인 필요

- 인천공항 **공식 주차장 요금** 기준표(단기/장기·터미널) 정본 URL·갱신 주기 — 절약액 산식용.
- 업체별 「현장 추가요금」고지 문구를 Firestore에 둘지, 공통 고지만 할지.
- 「사고 시 에어픽 중재」를 대외 카피에 쓸지 — 법무·약관 합의.
- CCTV·키 보관: 업체 필드에 실데이터가 있는 범위만 노출.

## 6. 한 줄 결론

이 작업의 범위는 **비교·상세에서 (1) 출처 있는 공항 대비 절약액 (2) 일당·구성·현장비 투명 고지 (3) 이미 있는 안심 기능을 한 블록으로 브랜드화**이고, 하지 않는 것은 **네오식 발렛 공포 카피·온라인 결제·사설 오픈 단정·숫자 창작**이다.
