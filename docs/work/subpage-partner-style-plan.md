# Plan: 메뉴·옆 페이지를 입점 페이지(/partner) 스타일로

> 2026-11-14 · 계기: 대표 「메뉴에 있는 곳들도 partner 양식처럼, 지금 너무 이상한 느낌」  
> **이 파일이 승인되기 전에는 코드를 쓰지 않는다.** 시안 스크린샷은 대화에 첨부(저장소 밖 임시 사본으로 렌더).

## 지금 문제

- 옆 페이지(가이드·FAQ·입점 업체·소개·사실 확인·요금·약관): 남색 통 히어로 + 회색 카드라서 입점 페이지(흰 바탕·격자·큰 제목)와 다른 사이트처럼 보임.
- ≡ 메뉴: 13개 항목이 같은 모양 카드로 나열됨. 「보험, 예약 전에 뭘 확인하나요?」처럼 긴 제목이 섞여 있고, 업체용 항목(카카오·이메일)이 고객 메뉴 가운데에 있음.
- 주소: `/partner`(업체 모집)와 `/partners/`(고객용 업체 목록)가 한 글자 차이.

## 바꾸는 것

### 1. 옆 페이지 공통 스타일 (`public/seo.css` 전면 교체)
- 입점 페이지 토큰 그대로: 흰 캔버스, 격자 배경 히어로 + 은은한 남색·금색 빛, 알약 배지, 굵은 큰 제목(모바일 32px / PC 46px).
- 직답 문장(AEO)은 흰 카드 「한눈에」 박스로 — 검색 답변용 문장 유지.
- 버튼: 남색 알약 + 흰 테두리 알약.
- 섹션: 큰 제목(26/34px), 짝수 섹션은 옅은 회색 띠, 번호 목록은 01·02 카드, 일반 목록은 금색 체크.
- 가이드 목록: 테두리 카드, PC 2열, 호버 시 그림자.
- HTML 구조는 거의 그대로 → SEO·구조화 데이터 영향 없음. 생성 스크립트(guides·partners·faq)는 클래스 변경 시에만 수정.

### 2. ≡ 메뉴 재구성 (`siteNav.ts`, `AppMenuSheet.tsx`)
- 맨 위 큰 버튼 2개: **주차대행 비교**(남색), **이심(eSIM)**.
- 알아보기: 가이드 · 자주 묻는 질문 · 요금 안내 · 보험 확인하기
- 에어픽: 입점 업체 · 에어픽 소개 · 사실 확인
- 남색 배너 「업체 사장님이신가요? → 입점 신청하기」(`/join`). 카카오·이메일 문의는 입점 페이지 안으로.
- 약관 3개는 맨 아래 작은 글씨 링크.
- 카드 나열 → 선 구분 목록(입점 페이지 느낌).

### 3. 주소 정리
- `/partner` → `/join` (예전 주소는 301로 자동 이동), `/for-partners/` → `/join/badge/`.
- `/partners/`는 고객용 업체 목록으로 유지. sitemap·canonical·링크 갱신.

### 4. 입점 페이지(/partner) 다듬기
- 첫 화면 제목이 「오르는 / 데,」로 어색하게 줄바꿈 → 줄바꿈 위치 고정.
- 오른쪽 폰 화면 안 버튼이 「제.」「실.」로 잘림 → 폰 화면 폭에 맞게 조정하거나 실제 스크린샷 이미지로 교체.
- 사진 교체 등 대표가 원하는 부분은 따로 받아서 반영.

### 5. 앱 우선 (유입은 앱이 더 많음 — 2026-11-14 대표)
- 앱 웹뷰 감지(`window.Capacitor?.isNativePlatform()`) → `<html class="is-app">`. 웹 브라우저는 영향 없음.
- 앱에서는 사이트 탭 줄(에어픽·주차대행 비교·이심…) 숨김 — 앱 메뉴·하단 탭과 중복.
- **하단 고정 버튼**: 「이심」 + 「주차대행 비교하기」(엄지 닿는 곳, 홈 바 여백 포함). 어느 글을 읽다가도 바로 예약으로.
- 히어로·섹션 여백과 제목 크기를 폰 기준으로 줄여 첫 화면에 핵심 답이 보이게. 버튼은 가로 꽉 차게, 높이 52px.
- 호버 효과 대신 누를 때 눌림 효과.
- 뒤로가기: 메뉴에서 왔으면 메뉴로 (지금 동작 유지).
- 글꼴(Pretendard)을 CDN 대신 앱 안에 포함 → 첫 표시 빨라지고 글꼴 깜빡임 줄임 (용량 확인 후 결정).
