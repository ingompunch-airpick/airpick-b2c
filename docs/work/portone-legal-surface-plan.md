## 정책 정합 (승인 시 고정)

1. **결제**: 「지금은 현장 결제. 앱 선결제 도입 시 약관·환불 페이지를 갱신한다」를 `/terms`·`/refund`에 명시.
2. **취소**: 입고 예정 **24시간 전**까지 앱 취소(선결제 없으므로 **환불할 대금 없음**). 24시간 이내·입고 후·일정 변경은 **입점 업체 문의**. 업체 사정 취소 시 안내·대체 등 중개자 협조(기존 consent 취지).
3. **약관 정본**: `src/constants/consent.ts`의 중개 약관(+필요 시 공통 조항)을 페이지·모달이 **한 소스**로 쓰거나, 정적 HTML을 그 내용과 **문장 단위 동기**. 클로드 초안으로 덮어쓰지 않음. 「공항공사 공식 아님」 문장 유지·추가 OK.
4. **중개자 고지**: 푸터에 전자상거래법 취지 문단(클로드 초안 마지막 문단과 동취지, 기존 `INTERMEDIARY_DISCLAIMER`와 맞춤).
5. **통신판매업**: `COMPANY_LEGAL`에 필드만 준비. **값이 확정되기 전 화면에 가짜 번호 금지.** 확정 후 한 줄 추가.

## 변경 체크리스트

### A. 상수·푸터 (크롤 1순위)

1. `companyLegal.ts` — 필요 시 `mailOrderNumber: string | null`, 정책 URL 상수(`/terms/` `/privacy/` `/refund/` `/pricing/`).
2. `SiteFooter.tsx` — `<details>` 제거 또는 기본 open + **항상 보이는** 텍스트 블록:
   - 상호·대표·사업자번호·주소·전화(`tel:`)·이메일
   - 링크: 이용약관 · 개인정보처리방침 · 취소·환불 정책 · 요금 안내 · 소개
   - 중개자 고지 1~2문장
3. `MarketingFooter.tsx` — 동일 사업자 한 줄 + 정책 링크 (파트너 랜딩 등).
4. 정적 페이지 공통 푸터 패턴: `public/about`, `privacy`, `faq`, `partners`, `guides` 주요 하단, `index.html` 셸, `parking.html`/`esim.html`에 **텍스트 링크** 보강 (봇이 JS 없이 읽게).

### B. 정적 정책 페이지

5. **`public/terms/index.html`** — 이용약관. 제목·본문에 「이용약관」. 내용 = consent 중개 약관 + 현장결제·중개 성격. 시행일 = 게시일(승인 시 기입).
6. **`public/refund/index.html`** — 제목에 「취소·환불」「청약철회」 포함. 현장결제·24시간 규칙·업체 문의·문의 전화/이메일. **선결제 환불 % 표 없음.**
7. **`public/privacy/index.html`** (+ `PrivacyPolicyPage.tsx` 동기) — 기존 유지. 보강만:
   - 결제 정보: 「현장결제 시 카드정보는 에어픽이 저장하지 않음. 앱 결제 도입 시 결제대행사 위탁을 방침에 추가」
   - 제3자 제공: 입점 업체 (기존과 동일 항목)
   - 위탁: Hosting = Google Firebase / 알림 = **확정된 상호만** (모르면 「고객 안내 발송 위탁」으로만 두고 상호는 메모에 남김)
8. SPA 라우트: `/terms` `/refund` `/pricing`를 `appPath` SEO prefix·필요 시 React 페이지 또는 **정적만** (about/privacy와 같이 정적 HTML 우선). `siteNav`·`AppMenuSheet`에 링크 추가.

### C. 상품·가격 (`/pricing/`)

9. **`public/pricing/index.html`** — 봇용 텍스트 필수.
   - **방식 A (권장)**: 고정 예시 일정 1개(예: T1·실내·출국/귀국 시각)로 앱과 **동일 견적 로직**이 내는 업체명·예상 요금(원)을 생성 스크립트 또는 수동 스냅샷으로 `<table>`/`<p>` 텍스트 노출. 상단에 「예시 일정 기준 예상 요금 · 실제 예약 화면 견적이 우선 · 현장 결제」.
   - **방식 B**: 대표가 준 요금표만 텍스트로. 숫자 창작 금지.
   - 「확정 최저가」단정·가짜 별점 금지. partners 「요금 안 박기」정책과 충돌 시: pricing만 예외(심사·고지용), partners 랜딩은 기존 유지.
