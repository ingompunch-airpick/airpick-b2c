# Plan: 실결제 오픈 (서버 결제 확인 · 결제 대기 · 자동 환불)

작성 2026-11-27 · 대표 결정 반영 · **승인 전 구현 금지**

## 대표 결정 (확정)
- 전액 선결제 (토스페이먼츠, 포트원 V2)
- 환불(기준 = 차를 맡기는 시간): 24시간 전까지 100% / 24시간 전~맡기는 시간 50% / 그 뒤 0%
- 결제 대기 **15분** — 지나면 자동 취소·자리 풀기 (설정값 하나로 변경 가능)
- 손님이 내 예약에서 취소 → 규정대로 **즉시 자동 환불**
- 업체가 취소 → **100% 자동 환불**
- 업체 정산(지급대행)은 토스 계약 후 별도 작업

## 흐름
1. 손님 「N원 결제하기」 → 예약 생성 `status: pending`, `payment.status: 'awaiting'`, `payment.holdUntil = 지금+15분`
   - 이때 자리(시간당·하루·주차 대수)는 바로 차지 — 지금의 생성 시 한도 검사 그대로
   - 알림톡·업체 알림은 **보내지 않음** (결제 확인 뒤)
2. 서버 `preparePayment(reservationId)` → **서버가 금액 계산**(요금표 + 허용 할인 + 포인트 차감) → `payment.amount`, `payment.paymentId` 저장 → 손님 화면은 이 금액으로만 결제창을 연다
3. 토스 결제창 → `/payment/complete?paymentId=`
4. 서버 `confirmPayment(paymentId)` + **포트원 웹훅**(창을 닫아도 확인)
   - 포트원 API로 결제 조회 → 상태 PAID · 금액 = `payment.amount` · 상점 일치 확인
   - 맞으면 `payment.status: 'paid'`, `paidAt` → 그때 알림톡·업체 알림
   - 금액이 다르면 전액 취소(환불) + 기록
5. 15분 안에 결제 없음 → 5분마다 도는 작업이 `status: cancelled`, `cancelReason: 'payment_timeout'`
6. **늦게 들어온 결제**(취소 뒤 결제 확인) → 자리 남아 있으면 다시 살려 확정, 없으면 전액 자동 환불 + 안내
7. 포인트로 전액 결제(0원) → 결제창 없이 바로 확정

## 취소·환불
| 누가 | 언제 | 환불 |
|---|---|---|
| 손님(내 예약) | 맡기는 시간 24시간 전까지 | 100% |
| 손님 | 24시간 전 ~ 맡기는 시간 | 50% |
| 손님 | 맡기는 시간 이후 | 셀프 취소 불가 → 카카오 채널 안내 |
| 업체(B2B에서 취소) | 언제든 | 100% |
| 결제 대기 시간 초과 | — | 결제 전이라 환불 없음 |

- 환불은 서버가 포트원 취소 API로 바로 처리하고 `refunds` 기록(금액·사유·시각·처리자)을 남긴다. 같은 예약 이중 환불 방지.
- 사용한 포인트는 **환불 비율과 같은 비율로 되돌림**(100%면 전부, 50%면 절반). 할인 쿠폰은 100% 환불일 때만 다시 쓸 수 있게.
- 지금의 업체별 「취소 마감 시간」(기본 24시간)은 결제 예약엔 적용 안 함 → 위 표가 기준.
- 업체 취소 감지: B2B가 `status`를 cancelled로 바꾸면 트리거가 결제 완료·미환불 건을 100% 환불. 손님 셀프 취소는 API가 먼저 환불하고 `cancelSource: 'customer'`로 표시해 중복 방지.

## 화면
- **B2C**: 결제 칸 그대로 + 완료 화면에 예약번호·「내 예약 보기」. 결제 실패·취소 시 「다시 결제하기」(15분 안이면 같은 예약). 내 예약 카드 취소 버튼에 「지금 취소하면 N원 환불(50%)」(`calcRefund` 문구 이미 있음).
- **B2B**: 결제 대기 예약은 목록에 회색 「결제 대기」 표시(자리 계산엔 포함). 결제 완료 예약은 「결제 완료」 배지. 업체가 취소할 때 「손님에게 전액 환불됩니다」 확인 창.
- 「현장 결제」 문구(FAQ·가이드·llms.txt) 오픈 날 일괄 수정.

## 테스트 · 오픈 단계
- 지금(심사 중): `?payreview=1` 심사용 화면은 그대로(예약 안 만듦).
- 내부 테스트: 토스 **테스트 채널** + `demo` 업체로만 끝까지(결제→확정→알림→취소 100%·50%→늦은 결제→시간 초과).
- 오픈: 토스 계약 완료 → 실채널 키 교체 → `paymentMode: 'live'`.
