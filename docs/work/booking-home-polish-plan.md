## 목표

손님이 접수 직전에 카카오 접수를 먼저 보고, 시트 글씨를 읽기 쉽고, 홈에서 실내·야외 가격 차이와 업체 목록 위치를 바로 알게 한다.

- 비회원 예약을 카카오 계정에 붙이기
- 오는 편명 선택 입력
- 색 체계 변경 (시트 `brand`는 이미 홈과 같은 남색 #0f1a2e)

## 변경 체크리스트

1. 확인 화면 (`BookingModal` confirming, 비회원일 때)
   - 노란 「카카오로 접수 · 첫 예약 N원」을 맨 위에.
   - 그 아래 「비회원으로 접수」 보조 버튼. 누르면 비밀번호 4자리 칸과 「비회원 접수」가 열린다.
   - 따로 있던 12px 「가입 후 첫 예약은 N원」 줄은 카카오 버튼으로 합쳐서 뺀다.
2. 시트 다듬기 (`BookingModal`, `PriceBreakdownCard`, `BookingPartnerSummary`, `BookingConsent`)
   - 카드의 `ring-1 ring-sky-border/70` 테두리를 빼고 `bg-[#f4f5f7]`로 홈 카드와 맞춘다.
   - 10·11·12px 글씨(항목명, 도움말, 오류)를 13px로 올린다.
3. 홈 (`HomePage`)
   - 주차장 칸 아래 한 줄: 지금 조건의 실제 최저가로 「실내 N원부터 · 야외 N원부터 · 실내는 대면만」. 업체가 없는 쪽은 뺀다.
   - 날짜 아래 「총 1박 2일」 칩을 「총 1박 2일 · N곳 보기」 버튼으로. 누르면 업체 목록으로 스크롤. 0곳·로딩이면 지금처럼 기간만.
   - 비로그인 카카오 배너를 맨 위에서 「이용 가능 업체」 바로 위로 옮긴다.
4. 비회원 완료 화면: 「카카오로 처음 접수하는 예약은 5,000원 할인됩니다.」 한 줄.
