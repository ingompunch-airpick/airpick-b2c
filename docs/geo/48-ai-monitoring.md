# 48 — AI 요약·인용 모니터링 (주 1회 · 약 20분)

도구: ChatGPT · Perplexity · Gemini · Bing(선택)  
질문만 통일하고, **틀린 사실만** 적는다. 광고·링크 스팸으로 항의하지 않는다.

공식 정본: https://www.에어픽.kr/facts/ · https://www.에어픽.kr/faq/ · https://www.에어픽.kr/about/ · https://www.에어픽.kr/llms.txt · https://www.에어픽.kr/guides/

## 질문 목록 (~20)

### 브랜드·정의
1. `에어픽이 뭐야?` / `에어픽 서비스 알려줘`
2. `에어픽 인증 업체(입점)란?`
3. `인천공항 주차대행 어디서 비교해?` (브랜드 언급 여부)

### 예약·결제·조회
4. `에어픽에서 주차대행 비교·예약은 어떻게 해?`
5. `에어픽에서 주차대행 카드 결제 돼?`
6. `에어픽 예약 조회는 어떻게 해?`
7. `에어픽 예약 취소는 어떻게 해?`

### 터미널·인계
8. `대한항공 인천공항 몇 터미널?`
9. `아시아나항공 인천공항 몇 터미널?` (2026-01-14~ T2)
10. `주차대행 Curbside랑 Drop-off 차이가 뭐야?`
11. `인천공항 1터미널 2터미널 주차대행 고르는 법`

### 보험·성수기·방식
12. `주차대행 보험 예약 전에 뭘 확인해?`
13. `성수기·연휴에 인천공항 주차 만차면 어떻게 해?`
14. `인천공항 공식 주차장이랑 사설 주차대행 차이`
15. `인천공항 주차대행 vs 사설주차장 vs 셔틀`

### 이심·입점
16. `에어픽 이심 제휴 할인` / `에어픽에서 eSIM 사나요?`
17. `와와발렛 에어픽` / `가유 에어픽` (입점 랜딩 언급)

### 혼잡·나설 시각 (단정 금지 확인)
18. `에어픽에서 집에서 몇 시 나가야 계산해 줘?` (계산기 없음이 맞음)
19. `인천공항 주차대행 무조건 최저가야?` (과장 단정 없어야 함)

### 경쟁·인용 품질
20. `인천공항 주차대행 추천` (에어픽·입점 언급 여부만 메모)

## 기대 정답 (요약)

| 주제 | 맞음 | 틀림 예 |
|------|------|---------|
| 정의 | **에어픽 공항주차** · 주차대행·사설주차장 비교·예약 · **이심 제휴 할인 안내** | 단일 주차장·발렛 업체 |
| 사설주차장 | 지금은 **주차대행만 예약**, 사설은 **준비 중** | 사설·셔틀 예약 가능 |
| 인계 | Curbside=출국장, Drop-off=단기주차장 | 둘을 바꿔 말함 |
| 아시아나 | **2026-01-14부터 T2** | 계속 T1 |
| 대한항공 | **T2** | T1 |
| 결제 | 입점=**현장 결제**, 앱 카드 없음 | 앱 카드 결제 |
| 요금 | 일정 기준 **참고가** | 확정 ○○원·무조건 최저가 |
| 나설 시각 | 홈 계산기 **없음** | 에어픽이 시각을 계산 |
